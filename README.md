# 🎵 Harmonix Mobile Music & Transfer

Мультиплатформенный мобильный аудиоплеер и центр миграции треков между **Яндекс Музыкой**, **VK Музыкой** и **Spotify**.

Разработан специально для смартфонов: доступен как **нативное Android-приложение (APK)**, так и в формате **PWA** (открывается в мобильном браузере и устанавливается на домашний экран без установки дополнительных пакетов).

## ✨ Возможности

### 📱 Мобильный интерфейс и анимации
- **Премиальный мобильный дизайн**: адаптирован под дисплеи смартфонов с поддержкой Notch и Dynamic Island (Safe Area insets).
- **Плавные жесты и анимации**:
  - Раскрытие плеера вверх (`slide up`) при нажатии на мини-плеер.
  - Сворачивание вниз (`drag down`) с физикой свайпа или по кнопке скрытия.
  - Горизонтальный свайп по обложке трека для переключения между треками.
  - Анимированная смена обложки (слева направо / справа налево).
- **Плавающий мини-плеер**: аккуратно парит над нижней панелью навигации без взаимных перекрытий.
- **Интеллектуальный Fallback для обложек**: если обложка недоступна или отсутствует сеть, отображается виниловый диск с вращением при воспроизведении.

### 🔒 Фоновое воспроизведение и Lock Screen
- Музыка продолжает играть в фоне при выключенном экране телефона.
- Поддержка **MediaSession API**: название трека, исполнитель и обложка отображаются в шторке уведомлений и на экране блокировки.
- Полное управление с беспроводных гарнитур (AirPods, Galaxy Buds и др.).

### 🔄 Центр переноса треков (Transfer Hub)
- Умный перенос треков между `Яндекс Музыка` ⇄ `VK Музыка` ⇄ `Spotify`.
- Алгоритм нечёткого сопоставления (`rapidfuzz`):
  - Очистка названий от мусора (`Remastered`, `feat.`, `Live`, `Official Audio`).
  - Проверка хронометража треков для исключения ошибочных версий.
- Живой прогресс-бар со статистикой найденных и пропущенных треков.

### 🔑 Простая авторизация
- **Яндекс Музыка**: Авторизация по OAuth токену или прямой ссылке на плейлист.
- **VK Музыка**: Быстрая авторизация в 1 клик через Kate Mobile OAuth (`audio,offline`).
- **Spotify**: Поддержка Spotify Web API (Access Token и Client ID/Secret).

## 🚀 Быстрый запуск

### 1. Запуск через готовый скрипт (Windows)
Просто запустите двойным кликом файл **`run.bat`**:
- Автоматически запустится бэкенд на `http://0.0.0.0:8000`.
- Откроется браузер с плеером.
- Во вкладке «Телефон» отобразится QR-код для подключения смартфона в локальной сети Wi-Fi.

### 2. Ручной запуск
**Бэкенд:**
```bash
cd backend
python -m venv .venv
# Активация окружения (Windows):
.venv\Scripts\activate
# Установка зависимостей:
pip install -r requirements.txt
# Запуск:
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**Фронтенд (разработка):**
```bash
cd frontend
npm install
npm run dev
```

### 3. Сборка Android APK
При наличии Android SDK и JDK запустите:
```bash
build_apk.bat
```
Собранный `.apk` появится в корне проекта: `Harmonix_Player.apk`.

## 🛠 Технический стек

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Capacitor (Android bridge), MediaSession API.
- **Backend**: Python 3.12, FastAPI, Uvicorn, RapidFuzz, Yandex Music API, Spotipy, HTTP Range Audio Streamer.
- **Тестирование**: Pytest (100% покрытие алгоритма нечеткого поиска и API).
